# Історія Home Assistant · ANMA Cloud 0.4.0

Замініть папку `custom_components/anma_cloud` у Home Assistant папкою з
`ANMA_HA_Integration_v0.4.0.zip` та перезапустіть Home Assistant.
Збережені прив'язки, вибрані сутності та ключ підключення залишаються.
Повторно додавати будинок на сайті не потрібно.

Сайт запитує Recorder через захищений канал ANMA. Канал віддає лише історію
вибраних джерел потужності, SOC та добової генерації. Поточні показники
оновлюються кожні 10 секунд, історія — раз на хвилину; кеш історії — 60 секунд.
Графіки охоплюють рухомі останні 24 години, незалежно від відкриття браузера.
Запис локальної телеметрії припинено; попередні записи не видаляються.

Погодинна генерація обчислюється за приростом лічильника `pv_energy_today`,
з урахуванням скидання лічильника. Якщо його історії немає, інтегрується
потужність `pv_power`; результат позначено ≈. Точність залежить від частоти
вимірювань джерела. Порожня історія й unavailable не означають нуль.
Поточна година неповна, майбутні — порожні. Часовий пояс — Europe/Kyiv;
у день переведення годинника може бути 23 або 25 годин.

Для перевірки відкрийте Live. Якщо показано запит оновити інтеграцію,
на HA ще працює стара версія. Якщо історія відсутня, перевірте, що джерела
не виключені з Recorder. Сайт не може відновити дані, яких HA не записував.
