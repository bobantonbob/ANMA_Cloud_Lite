# ANMA Cloud 0.4.2

Замініть custom_components/anma_cloud та перезапустіть Home Assistant.
У налаштуваннях залиште Power (Вт/кВт) та виберіть «Стан акумулятора».
Нове поле замінює «Код помилки». Два поля потужності заряду/розряду прибрано.
Підтримуються charge/charging, discharge/discharging, idle/standby/not charging.
Регістр і крайні пробіли ігноруються. Невідомий стан означає невідомий напрямок.
Power задає абсолютну потужність, стан задає напрямок потоку і знак історії.
Для idle потік зупинений, фактичний Power залишається видимим.
Без прив'язки стану діє попередня логіка знака Power.
Збережіть налаштування; повторна прив'язка будинку не потрібна.
