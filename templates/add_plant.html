Встановіть ANMA Cloud

1. Через HACS — рекомендовано

Додати через HACS →

Потрібен налаштований HACS. Додайте репозиторій один раз — потім ANMA Cloud буде доступний у пошуку вашого HACS та отримуватиме оновлення.

  1. Відкрийте посилання та додайте ANMA Cloud. Або HACS → ⋮ → Custom repositories → bobantonbob/anma-cloud, тип Integration.
  2. Натисніть Download і перезапустіть Home Assistant.
  3. Налаштування → Пристрої та служби → Додати інтеграцію → ANMA Cloud.
2. Без HACS — встановити вручну

Завантажити ZIP інтеграції ↓

Розпакуйте архів. Скопіюйте папку custom_components/anma_cloud у /config/custom_components/anma_cloud вашого Home Assistant, перезапустіть його та додайте інтеграцію ANMA Cloud.

Підключіть будинок

  1. У налаштуваннях ANMA Cloud виберіть і збережіть сутності.
  2. Відкрийте «Підключення сайту» й створіть одноразовий код.
  3. Введіть назву будинку, Tailscale IP та код у формі. Код діє 15 хвилин.

Сервер ANMA та Home Assistant мають бути у доступній мережі Tailscale. Підключення дозволяє лише читати вибрані показники.
